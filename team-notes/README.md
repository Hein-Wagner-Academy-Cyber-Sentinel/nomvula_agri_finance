# Team Notes

    **Phase: All year**

Messages and notes between the pair (Lutho and Michael). Use this folder to keep the team aligned and to leave a written record of decisions.

## What belongs here

- **Daily alignment answers** — the three questions from [`GIT_RULES.md`](../GIT_RULES.md): which files you are changing, whether you are ready to merge, and whether the work needs a joint review.
- **Meeting notes** — what was discussed, what was decided, who owns each action.
- **Handover notes** — where you stopped, what is half-done, and what the other person should pick up.
- **Messages to your teammate** — anything that should be in writing instead of only said aloud.

## Naming

One file per note, named by date and topic so they sort in order:

```
YYYY-MM-DD-topic.md
```

For example: `2026-11-27-bicep-merged-into-main.md`.

## Rule

Like everything else in this repository, notes are plain text (Markdown). No screenshots.
